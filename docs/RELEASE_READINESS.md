## Required GitHub/production secrets

- Generative makeup: optional `OPENAI_API_KEY`. Add it in [GitHub Actions secrets](https://github.com/mipox331-netizen/makeupart-v8/settings/secrets/actions), then run the Modal Production Deploy workflow. Never paste the secret into chat or commit it. The deployment runtime logs only whether the provider is configured, never the key.
- Google Play: `GOOGLE_PLAY_SERVICE_ACCOUNT_JSON` plus the Android signing secrets used by the release workflow.
- Encrypted database and media backup: valid production database / Modal credentials and `BACKUP_ENCRYPTION_PASSPHRASE` (minimum 24 characters, with a recovery copy stored offline). Media backup is capped at a 3 GiB source volume per runner execution; larger volumes fail safely rather than upload a partial archive.
- Provider keys, certificates and passwords belong only in GitHub Secrets / the production environment. Never paste secret values into chat or source code.

A successful CI/deploy or empty-database/media restore is not proof of full commercial license approval, Google Play publication, iOS distribution or recovery of real application/customer rows. See [Media Backup](MEDIA_BACKUP.md) and [Third-party license audit](THIRD_PARTY_LICENSE_AUDIT.md).
