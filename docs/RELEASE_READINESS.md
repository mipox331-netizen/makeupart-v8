## Release gates still open

1. Configure the real production HTTPS `API_BASE_URL` and pass live, ready and durable-media readiness checks.
2. Restore the matching persistent signing keystore as `ANDROID_KEYSTORE_BASE64`, then produce an update-compatible release APK.
3. Reauthorize Google Drive and align the actual production media store with the server-side backup/restore workflow; complete a non-empty backup and isolated restore.
4. Run real Android device tests for camera/gallery, photo processing, local Gallery backup, low-storage failure handling, login, consent, watermark, before/after, export and update installation.

A green CI or a valid debug APK is not proof of a production API, a signed release APK, store availability or full disaster recovery.
