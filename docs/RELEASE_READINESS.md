## Required production checks

1. **Google Drive configuration:** in Render Dashboard → `makeupart-api` → Environment, set `GOOGLE_DRIVE_CLIENT_ID`, `GOOGLE_DRIVE_CLIENT_SECRET`, `GOOGLE_DRIVE_REFRESH_TOKEN`, `ENVIRONMENT=production`, and `REQUIRE_DURABLE_MEDIA=true`. Production media operations are now fail-closed when Drive credentials are absent. If those credentials are missing or invalid, the API should report not ready/503 rather than quietly keep customer photos only on the ephemeral local disk.
2. **GitHub backup environment:** set the same three Google Drive OAuth secrets separately under repository Settings → Environments → `production`, plus a unique `BACKUP_ENCRYPTION_PASSPHRASE` of at least 24 characters. Render variables are not automatically visible to GitHub Actions. Keep the passphrase offline; do not paste it into chat or commit secrets.
3. **Real-media test:** in the app, process a photo you own or have permission to use. Confirm a successful response, confirm the input and output are in the private Drive media root, restart the service, and download/open both images again. Then rerun the media backup and restore drill and verify a non-zero file count and matching checksums. Do not call photo recovery complete before this passes.
4. **Android release signature:** configure `ANDROID_KEYSTORE_BASE64`, `ANDROID_STORE_PASSWORD`, `ANDROID_KEY_PASSWORD`, and `ANDROID_KEY_ALIAS` from the same persistent signing keystore. Never replace the key for subsequent releases intended to update existing installations.
5. **Final device verification:** install on a real Android device; test registration, sign-in, trial/subscription screen, selecting client, consent reset, photo picker/camera, processing, watermark/logo, before/after view, gallery export, logout, and a fresh login. Automated Flutter tests do not replace this check.

Passing source CI and a recent health response do not by themselves prove durable media, signed release compatibility, Play Store publication, or successful operation on a real device.
